# Security and Privacy

この文書は、Backlog to Google Calendar Helperのデータ取り扱いと、プロトタイプとしての注意点をまとめたものです。

## 外部通信

この拡張機能は、Backlog APIやGoogle Calendar APIを使ったサーバー間連携を行いません。また、独自の外部サーバーへBacklog課題情報を送信するコードは含まれていません。

ブラウザ上では、対象ページとして以下へアクセスします。

- `https://*.backlog.com/*`
- `https://*.backlog.jp/*`
- `https://calendar.google.com/*`

## 取得する情報

Backlog課題詳細ページから、主に以下を取得します。

- 課題キー
- 課題件名
- 起動時に表示していたBacklog URL

これらはGoogleカレンダーまたはGoogle Tasksへの入力補助にのみ使用します。

## ローカル保存

課題情報はブラウザ拡張の `chrome.storage.local` に一時保存します。現行Chrome版・Edge版ともに約90秒を有効期間として扱い、入力完了時または期限切れ時に削除する実装です。

## クリップボード

自動入力の補助および自動入力失敗時の手動貼り付けに備えて、課題情報をOSのクリップボードにもコピーします。

`chrome.storage.local` の一時データと異なり、**クリップボードの情報はこの拡張機能から自動削除しません**。OSのクリップボード履歴やデバイス間同期を有効にしている場合、課題名やURLが履歴・同期対象になる可能性があります。

機密性の高い課題を扱う場合は、組織の情報管理ルールとOSのクリップボード設定を確認してください。

## 権限

現行版では、ブラウザやバージョンに応じて以下の権限を使用します。

- `storage`
- `tabs`
- `clipboardWrite`
- `activeTab`
- `scripting`

公開にあたり、動作実績のあるプログラム本体を変更しない方針のため、権限の削減・再設計は行っていません。

## プロトタイプとしての制約

この拡張機能はGoogleカレンダーの画面DOMに依存します。Google側のUI変更、言語設定、A/Bテスト、ブラウザ更新などによって自動入力が動作しなくなる可能性があります。

Chrome Web Store / Microsoft Edge Add-onsでの正式配布・審査を前提とした製品ではありません。利用する場合はコードと要求権限を確認し、自己の環境・組織ポリシーに照らして判断してください。
