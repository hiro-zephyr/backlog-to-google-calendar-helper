# Edge版 v0.6.1

Backlog to Google Calendar HelperのMicrosoft Edge向けプロトタイプです。

## ショートカット

- Calendar: `Alt + Shift + L`
- Task: `Alt + Shift + K`

Edge標準ショートカットとの競合を避けるため、CtrlではなくAltを初期値にしています。

## インストール

1. このフォルダ、または `packages/backlog-to-google-calendar-helper-edge-v0.6.1.zip` を展開したフォルダを用意する
2. `edge://extensions/` を開く
3. 開発者モードをON
4. 「展開して読み込み」からフォルダを選ぶ
5. `edge://extensions/shortcuts` でショートカットを確認する

プロトタイプとしての注意事項とデータの扱いは、リポジトリ直下の `README.md` と `docs/SECURITY_AND_PRIVACY.md` を参照してください。
